# 小小音樂家的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，曲子都是為這個 APP 新寫的。只有一個例外：垃圾車放的是〈少女的祈禱〉（巴達捷芙絲卡 1856 年寫的）開頭一句，因為台灣的垃圾車就是放這首；這首曲子早就是公共財，播它的音樂盒也是這裡合成的。**這一句是憑記憶寫的，請用耳朵聽聽看像不像，不像告訴我改。**

- 合成用的小工具（木琴泛音、撥弦、玩具小喇叭、接成循環、量音量、人聲的共鳴方法……）是從小小生活家的 `design/sounds/make_sounds.py` 複製過來的。
- 新做的有：十隻動物的嗓子和牠們在樂團裡唱的那一小段、木琴、五個鼓、鍋碗瓢盆、台灣生活的聲音、三首曲子和全部的音效。

做的時候沒辦法用耳朵聽，是看數字（長度、音量、破音、接頭）檢查的；請在手機上聽聽看，覺得哪個不像、不好聽再改。

## 怎麼產生

```
pip install numpy scipy                                     # 只要第一次
python3 design/sounds/make_sounds.py                        # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py preview 試聽.m4a        # 再做一個試聽檔（要 ffmpeg）
python3 design/sounds/make_sounds.py band 樂團.m4a           # 十隻動物一隻一隻加進來一起唱
python3 design/sounds/make_sounds.py tap xylo_0             # 只重做這幾個
```

- 亂數都用固定的種子（每個聲音自己一個），每次跑出來的檔案都一模一樣。
- 程式會檢查：檔名剛好是下面這些、樂團每一段的長度一模一樣（見下面）、音效頭尾都是 0、沒有破音、循環的接頭沒有「啪」一聲、全部加起來不超過 15,000,000 bytes。目前 102 個檔，約 9.2 MiB。

## 「怎麼敲都好聽」
1. **只有一個調**：所有有音高的聲音都只用 C 大調五聲音階（Do Re Mi Sol La），程式會擋下不在裡面的音（`pentatonic()`）。垃圾車的〈少女的祈禱〉是唯一例外：它只在「聽聽看」單獨播放，不會和別的一起響。
2. **同一個速度、一樣長**：動物樂團每一段都是兩小節（8 拍），做成三種速度，每種速度的檔案**樣本數一模一樣**：

   | 速度 | 每分鐘 | 一段 | 樣本數（16,000 Hz） |
   |---|---|---|---|
   | 慢（蝸牛） | 80 拍 | 6.0 秒 | 96,000 |
   | 中 | 100 拍 | 4.8 秒 | 76,800 |
   | 快（兔子） | 120 拍 | 4.0 秒 | 64,000 |

   換速度是重新合成一份（不是拉長），音高不變。一段的結尾還在響的聲音接回開頭，循環聽不出接縫。
3. **同一組和弦**：每一段的第 1 小節是 C、第 2 小節是 A 小調（兩個都只有五聲音階的音），所以哪一隻的低音都配得上哪一隻的旋律。
4. **鼓沒有音高**；兩個中鼓調在 Sol 和 Do。

## 格式
- 全部是 WAV、單聲道、16 位元。樂團和曲子 16,000 Hz；音效 22,050 Hz。
- 音效調成「從手機喇叭聽起來」一樣大聲（約 −21 dB，按鈕這些輕一點），最大音量不超過 0.72（約 −3 dB），沒有突然的大聲。鼓和咚咚的低音先用柔和的限幅（`squash`）壓掉第一下的尖峰，才不會比別的小聲很多。
- 樂團每一段一隻單獨約 −28 dB、最大 0.42；APP 每隻用 0.7 的音量放，十隻一起最大約 0.83，不會破音。
- 曲子比音效輕 8～12 dB。APP 裡再加家長設定的音量上限（預設 70%）。

## 檔案

### 動物樂團（`band_<動物>_<速度>.wav`，速度 slow／normal／fast）
| 動物 | 檔名 | 嗓子 | 唱什麼 |
|---|---|---|---|
| 小熊 | `bear` | 撥弦低音提琴，一點抖音 | 每拍一下：C C G C ／ A A E A |
| 青蛙 | `frog` | 有雜音、會抖的「呱」 | 鼓的節奏 |
| 小鳥 | `bird` | 滑進音的口哨（像笛子） | 主旋律 Mi Sol La ／ Sol Mi Re |
| 小貓 | `cat` | 拉長的鼻音「喵～」 | 每小節一個長音 Sol／Mi |
| 小狗 | `dog` | 短短的「汪」 | 切分的伴奏 |
| 小象 | `elephant` | 低低的玩具號角「叭」 | 每兩拍一下的第二低音 |
| 台灣黑熊 | `blackbear` | 大鼓加低低的「吼」 | 每小節第一拍的重音 |
| 石虎 | `leopard` | 刷子和沙鈴「嘶～沙沙」 | 輕輕的八分音符 |
| 藍鵲 | `magpie` | 尖尖的「嘎」加木魚 | 每小節最後一拍回答小鳥 |
| 小鴨 | `duck` | 帶鼻音、像口琴的「呱」 | 反拍 |

### 敲敲樂
| 檔名 | 是什麼 |
|---|---|
| `xylo_0`～`xylo_7` | 木琴 C5 D5 E5 G5 A5 C6 D6 E6（小小用前 5 個） |
| `drum_0`～`drum_4` | 大鼓、低的中鼓（Sol）、高的中鼓（Do）、小鼓、鈴鼓 |
| `pot_0`～`pot_4` | 鍋子、鍋蓋、碗、杯子、湯匙 |
